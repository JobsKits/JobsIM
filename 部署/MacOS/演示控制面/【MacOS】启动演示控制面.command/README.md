## 🔥 <span id="前言">前言</span>

[双击入口](./【MacOS】启动演示控制面.command)在本机准备当前原生后端／Web成品并保持有限HTTPS控制面前台，供iPhone登录设置开关幂等启动独立demo。不会运行默认9443实例；详细边界见[宿主说明](../README.md)。

## 一、<span id="arguments">选项</span> <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

默认先展示范围并回车确认；`--yes`表示明确同意本入口说明的固定范围，`--prepare-only`只准备并生成公开描述，不监听控制端口，`--help`只显示帮助。入口不接受任意命令、端口或实例路径，不联网下载工具或全局安装。构建失败保留日志，不启动旧产品；Ctrl+C只对本入口持有的专属demo执行精确保留数据收尾。
