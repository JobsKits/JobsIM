## 一、执行

```shell
JOBSIM_PLAYWRIGHT_MODULE=/已有/playwright模块 \
JOBSIM_MIGRATION_REPORT=/本轮未使用的新目录 \
node 测试/前端/Web/migration.cjs/migration.cjs
```

从脚本位置定位项目，既有Vite随机回环端口、`configFile:false`，全部真实`/api`阻断；使用既有Chrome／Playwright，不安装依赖、不接用户账号。启动4GiB门禁，已有报告目录拒绝覆盖。执行前后逐字节核候选源码并保存快照；失败保留已过项和当时输入，不能当最终通过。

## 二、候选范围

当前33组覆盖原nonce／选择／摘要先耐久、双未知、只查零创建、展示变化不改规范化输入、后继family门禁、CV改变拒绝、RAM秘密、cloud_only／Outbox拒绝、转发零正文持久与实时再核、实际AES-GCM、原件精确字节、坏capsule／AAD、取钥中换身份、过期install授权、最终global门禁、已导入Blob清理、服务器回报未知／已报告不重签、取消暂存、真实事务abort、较新CV保留／同CV冲突整批拒绝、包内毒字段、原JSON片段SHA／重复key、十语及实际管理员表单／藏文窄屏。另实测global通知即清已显示正文、已报告状态禁新交付与入口后台清RAM。
