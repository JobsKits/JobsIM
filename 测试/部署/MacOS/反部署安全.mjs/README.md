## <span id="jobs-toc-heading-1" data-jobs-toc="v2">一、范围与执行 <a href="#前言">🔼</a> <a href="#🔚">🔽</a></span><!-- jobs-toc:heading-end -->

使用已有Node运行同目录 `反部署安全.mjs`，从当前两份正式MacOS实现读取函数，在中文/空格临时目录验证原点、逐项清理、独立journal和实例钥保护、未知/链接/替换/并发变更、断点、reference及确认/失败门禁。只用合成普通文件，不启停数据库或用户实例，不安装依赖。

默认报告写项目中央的成对部署反部署MacOS专项；`JOBSIM_UNDEPLOY_REPORT`可指定新目录。保留逐组日志、结果及源码前后SHA，失败退出非零，测试依赖与正式原生脚本依赖分开。
