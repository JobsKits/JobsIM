# 规范入口 HTTPS 回归

仅对明确指定的独立回归实例执行。先用[MacOS部署运行入口](../../../部署/MacOS/Deployment/【MacOS】部署JobsIM.command/【MacOS】部署JobsIM.command)启动，再提供该实例外置 `--state`、公开 `--deployment` 和报告 `--output`，同时传入 `--yes`。依赖已有 Python3 标准库，不安装软件、不绕过TLS、不启动或接管服务。

脚本会创建三个随机测试账号、好友关系、私聊与群聊，并真实发送消息、修改群策略、审批邀请和解散测试群。凭据仅保存到指定实例目录内600权限的独立文件，输出只记录HTTP路径／状态，不输出口令或令牌。不能指向真实用户实例。失败保留现场且退出非零，不将局部断言称为完整产品验收。

覆盖严格证书握手、注册、好友、双向消息及幂等结果、群策略代际、跨设备共同慢速行、禁言不撤阅读、解除禁言不复活旧准入、明确管理员豁免、成员分页、限次审批邀请及解散后云访问拒绝。原生设备、真正跨设备并发、独立journal恢复与文件清理另验。
