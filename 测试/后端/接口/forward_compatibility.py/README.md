## <span id="jobs-toc-heading-2" data-jobs-toc="v2">二、实验导出明确拒绝</span><!-- jobs-toc:heading-end -->

同入口加`--export-only`只跑受控聊天导出：创建含forward的本人测试范围，实验服务接受异步任务后必须failed、failureCode=FORWARD_EXPORT_UNSUPPORTED，完成prefix清理且无active forward holder。[11次HTTP／3语义证据](../../../../项目相关报告/测试/后端/转发导出明确拒绝实测.json)证明未把源投影复制成缺少链级责任的包。需要显式实验服务，默认chat_export仍false；不能用此失败测试冒充完整本人数据导出通过。

默认报告现直接写入工程根 `项目相关报告/测试/后端/执行记录/本轮唯一目录/`，Node 使用时间与 PID，Python 使用 UUID，避免覆盖迁入的历史固定文件。原有显式报告参数／环境变量优先；请选择新目录。本轮只核对独立执行目录表达式和脚本语法，没有重新运行业务测试或真实接口。
