# 运行规则测试.command

[同名zsh入口](./【MacOS】运行规则测试.command)使用现有镜像SDK的Node和TypeScript，仅将本工程Models／Strings纯规则转译到用户缓存，然后以Node内置test执行[Unit用例](../Unit/Policies.test.mjs)。不下载工具、不修改全局配置，也不修改第三方SDK。

覆盖联系人入站资格、只读群、原成员代际、大整数游标、连接／账户／设备／恢复代次隔离、认证用途JSON、HTTPS描述和十语控制键。结果位于相邻报告时间目录。此主机结果不能代替ArkUI、AssetStore、RDB或设备Hypium执行；后者见[测试总览](../README.md)。
