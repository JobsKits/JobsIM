# 结构化提及与群公告真实接口验证

用本机已有 Python 3 标准库执行，不安装依赖。私密环境文件由本项目 Integration 夹具提供；只读取 HTTPS 地址、受控 CA 与 PostgreSQL 测试连接，凭据不会写入报告。脚本会创建隔离测试账号、群、消息、公告，末尾注销临时会话；适用于本任务测试实例，不用于生产数据。

```shell
python3 ./mentions_announcements.py --environment-file /选择的私密环境文件.json
```

默认报告按脚本位置写入 `测试/后端/报告/提及与公告实测.json` 及 SHA256，可用 `--report` 指定独立报告路径。验证结构化成员选择、原发送资格、拉黑提醒抑制、群主 @all 与独立限频、原操作幂等、公告源编辑／撤回／过期／重入占位、转让权限以及只读消息原结果不创建。并发用本项目 PostgreSQL 行锁控制源编辑／公告提交顺序，最后释放锁；不改系统信任、不停服务。

测试实例须采用默认提及频控，且含新公告与 message-results 路由。报告区分真实 HTTP／数据库断言；不代表前端、真机、厂商推送或跨主机围栏已验收。失败打印错误码及路径，正文和凭据保持脱敏。
