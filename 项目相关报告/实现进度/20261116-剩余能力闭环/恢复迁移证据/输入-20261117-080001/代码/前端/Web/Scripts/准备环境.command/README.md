## 一、用途与操作 <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

双击同目录的[准备环境.command](./准备环境.command)，回车执行，输入空格后回车取消。`--check` 仅检查 Node/npm；`--yes` 用于已知范围的自动执行。

依赖安装到用户缓存，工程只创建依赖链接；已有实体目录或不同链接时保留现场并停止。失败后可重新执行，锁文件和 npm 校验继续生效，不需要全局升级工具。此入口只准备依赖，服务启动／停止／备份见[部署目录](../../../../../部署/README.md)。

## 二、代码地图 <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

`main` → `init_paths` 从脚本位置确定工程 → `check_tools` 检查用户现有工具 → `prepare` 复制锁文件、安装缓存依赖并创建受控链接。`JOBSIM_WEB_CACHE` 可指定缓存目录。
