## <span id="jobs-toc-heading-3" data-jobs-toc="v2">二、维护边界 <a href="#前言">🔼</a> <a href="#🔚">🔽</a></span><!-- jobs-toc:heading-end -->

- 新执行报告默认写入本目录对应责任域 `执行记录/` 的唯一子目录（或显式指定新子项），禁止覆盖不同字节的同名历史输出；报告应注明源码／构建、环境、注入边界、失败和跳过。
- 原始 JSON、PNG、log、旧校验清单和冻结包字节保留；导航允许更新相对链接，原导航另存。JSON 内历史 sourceSHA／旧路径保留原意，不能按新路径重解释。
- 原 `测试/**/报告` 和 `需求/实现进度` 为相对兼容链接，只用于历史导航；各工具默认直接解析新中央目录，不依赖 Windows 能运行目录软链接。
- 私密环境、数据库、CA 私钥、凭据与唯一备份均在工程外，不收进报告。开发持久状态使用系统 Application Support，备份使用独立 Documents 目录。
