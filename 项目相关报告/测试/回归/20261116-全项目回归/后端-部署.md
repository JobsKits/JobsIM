## 🔥 <span id="前言">前言</span>

本轮覆盖当前 [**Go**](https://go.dev/) 后端、31份外置测试与三端部署源码。真实专项使用本轮新建的双物理 [**PostgreSQL**](https://www.postgresql.org/) 18.7、独立 JetStream、9个生产内部角色与严格 HTTPS；没有连接、启停或迁移用户既有实例。指定用户实例的 `TLS/` 只读核查为空，没有旧 CA／服务端证书可被本轮重签。

## 四、<span id="commands">命令、输入与资源边界</span> <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

以下命令从仓库根执行，`GO_BINARY` 指向本轮既有Go1.27.4，未下载、升级或清缓存：

```shell
GOMAXPROCS=2 GOPROXY=off GOTOOLCHAIN=local \
  python3 测试/后端/运行测试.py --backend-only --go "$GO_BINARY"

GOMAXPROCS=2 GOPROXY=off GOTOOLCHAIN=local \
  "$GO_BINARY" -C 代码/后端/Go vet ./...

GOMAXPROCS=2 GOPROXY=off GOTOOLCHAIN=local \
  "$GO_BINARY" -C 代码/后端/Go test -p 1 -count=1 -json \
  -overlay "$REPORT/全外置overlay.json" -timeout 90s ./...

python3 测试/后端/接口/integration.py \
  --server https://127.0.0.1:59443 --ca-file "$PRIVATE_RUN/TLS/ca.crt"
```

最后一次PG测试显式启用 `SYNC_SCHEMAS`、`SYNC_OUTBOX`、`DRAFT_FLOOR`、`SOURCE_PREFERENCES`、`SELF_READ`、`READ_POINT` 六类 `JOBS_IM_*_TEST=1`，维护URL仅指向本轮62381集群，私有 `PGPASSFILE` 位于本轮UUID的Safety/Secrets；另提供独立迁移、发送围栏和实验导出环境文件。9个跳过的方法未注入其要求的旧专域seed。动态环境值、口令、CA私钥及测试actor都留工程外，不写入报告。具体夹具命令快照见[PG执行片段](./后端证据/PG隔离执行片段.txt)、[HTTPS合同片段](./后端证据/HTTPS合同执行片段.txt)、[TLS函数片段](./后端证据/TLS函数执行片段.txt)。

最终源码与测试摘要见[最终输入SHA256](./后端证据/最终输入SHA256.json)。首轮超时由测试总超时中止，可能保留本轮私有PG中的独立角色测试库；最终已停止该双集群并保留现场，不能把指定六类随机合同库统计为0外推为清空所有失败现场。用户既有实例a4c…未启动，任何测试密码、令牌或新CA都未写入该实例。
