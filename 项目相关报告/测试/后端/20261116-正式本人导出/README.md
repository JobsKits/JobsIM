## 🔥 <span id="前言">前言</span>

> 正式本人导出后端已封存限定真实验证，最终候选 `chat_export=true`。本页不是五端入口、全 I 或 243 项验收结论。原失败、原请求意图和清理责任全部保留；后续源码不追认本页冻结 binary。

## 一、<span id="scope">实现边界</span> <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

- 正式本人 ZIP 包含受控当前公开账号／设备元数据、资料／静态头像、关系、获权会话／成员、公告纯引用、本人view／read／已应用文本草稿／字号偏好、本人举报理由与公开状态，以及普通消息和附件。转发只出占位，不交付来源正文、附件许可或临时proof。
- 私有制品服务端加密存储，下载完整认证后经 TLS 交付 ZIP；密钥不交给普通客户端。创建、查单、取消、短期下载票据与源撤权使用独立正式生命周期，旧实验入口保持隔离。
- 本轮仅使用全新正式导出独立域 `58443`；固定 `57`、`7ef` 及客户端 `E2` 域不改。实例密钥、数据库、私密进度和备份位于工程外持久目录，不进入本报告。
