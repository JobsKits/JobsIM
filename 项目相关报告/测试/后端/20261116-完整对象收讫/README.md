## 🔥 <span id="前言">前言</span>

本切片在既有[正文收讫](../20261116-收讫与草稿实现/README.md)之上增加独立原件回执。收到附件描述、地址或预览不算保存原件；当前仍未具备冻结完整目标、连续累计ACK和云清理worker，`after_receipt`保持false，不将单设备对象事实提升为全体送达。

## 一、<span id="implementation">实现范围</span> <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

- [存储批准](../../../../代码/后端/Go/sync_receipt_policy.go)增加 `native_sqlite_full_file_fsync_v1`，验证报告须覆盖完整原件文件与父目录fsync，以及SQLite FULL事务。旧 `native_sqlite_full_v1` 仅正文合格，不自动获得对象资格。资格表持久保存合同；合同变化必须新声明并旋转qualification，原声明重试仍只回原结果。
- [对象收讫](../../../../代码/后端/Go/sync_object_receipts.go)以同实例／本人／设备／物理库／epoch／qualification的**既成正文回执requestId**为父，独立 `ro1` 绑定原正文摘要、内容版本、权限、对象ID、完整十进制字节数和SHA。未知原单只查404；既成原结果先返回，过期或撤销不重建旧事实。新提交在跨owner校验后，仅本域事务锁库／资格／epoch及父事实，提交前再次检查时限，数据库使用 `clock_timestamp()` 再拒过期。
- [媒体owner](../../../../代码/后端/Go/media_receipts.go)只接受sync调用及匹配实例的持锁证明，重验当前消息附件授权、purpose与绑定；实际打开普通原文件，核大小和有界全文件SHA，拒符号链接、缺失、同大小篡改和非原件引用。公共原件GET／HEAD完整响应同样持SH，源EX写入等待响应排空。
- 新事实只保存最小身份、摘要和结果，不复制正文、对象字节或原证明。单设备结果的 `objectComplete:true` 只指该原件；`targetRangeComplete/deletionEligible:false`。部署批准是运维批准记录，不能远程证明客户端已落盘或实际运行该构建。

## 三、<span id="reproduce">复现与现场</span> <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

复现入口与门禁见[专项脚本](../../../../测试/后端/接口/object_receipts.mjs/README.md)。数据库验证使用原独占角色在共享物理测试集群内新建随机空库，结束后逐库删除；没有触碰E2、S1、7ef或正式导出的业务库，没有重启其服务或变更实例身份。传入的隔离TLS地址只是连接门禁参数，本轮不访问该地址。
