## 🔥 <span id="前言">前言</span>

JobsIM 是面向个人和小团队的自托管即时通讯软件，目前在研，由 Jobs 维护。第一阶段先打通基础聊天和部署闭环。iOS、Android、HarmonyOS分别采用原生工程，Web为同时适配桌面与手机H5的React/TypeScript应用，CLI与后端使用Go。已有需求统一归入[需求目录](./需求/README.md)，不复制第二套版本。

当前iOS界面源码按[原生交互与验证](./项目相关报告/测试/前端/iOS/20261118-UI整改/README.md)组织为联系人／消息／当前账户三Tab；认证图片背景与毛玻璃卡片、右上齿轮独立连接设置、用户档案和统一按钮空态采用同一主题。Mac独立演示实例通过登录设置启用，明文预填专用账户后正常登录，单可拖浮标退出至登录。当前build-16候选105项隔离单元方法通过；ui-tests-12内的主题三态／返回个人中心、本人档案／头像入口／统一空态已实际通过并复核截图，ui-tests-13内认证／浮标退出已通过。上述两轮仍分别保留4项／1项失败原件；举报材料预览与布局补正、档案保存完整边界增强正在新候选复验。此前device-build-5已有效签名并在iPhone安装／启动；尚不能借其追认最新源的手机交互。完整243项仍未验收。

| 消息与治理 | 基础文本／附件、编辑撤回、回复、原引用转发、反应、置顶收藏、好友与群、结构化提及及群公告；头像、举报、账户封禁墓碑服务已实测；各端UI覆盖程度见实现进度 |

| 工程 | 十语言、白天／黑夜／系统主题、字号、演示回退；没有热更新／外部崩溃收集／生产CI/CD交付声明；诊断和测试日志在各自报告目录 |
| 后端 | 原操作幂等、版本比较、资格围栏、限流、事务交接与能力开关；正式本人导出后端已验，端侧全链路未齐；强保护／after_receipt关闭，未宣称全局分布式锁或完整链路追踪 |
