## 二、离线行为 <a href="#前言">🔼</a> <a href="#🔚">🔽</a>

Logo、图标和字体随应用提供。头像和图片消息由已认证的自托管接口读取，加载完成前及失败时保留本地Logo。接口不可用时仍可预览独立本地演示，操作不补发给真实用户。
